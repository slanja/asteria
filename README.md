# asteria

![Preview](preview.png)

Personal dotfiles built around the Hyprland compositor. Minimalistic and nature inspired look.

## General information

### System Specifications
- **OS:** Arch Linux
- **WM:** Hyprland
- **Terminal:** Kitty
- **File Manager:** HyprFM
- **App Launcher:** Fuzzel
- **Status Bar:** Wayle
- **Monitor Manager:** Hyprmoncfg

### Keybinds

#### General
<kbd>SUPER</kbd> <kbd>Return</kbd> - open terminal

<kbd>SUPER</kbd> <kbd>C</kbd> - close window

<kbd>SUPER</kbd> <kbd>Escape</kbd> - exit session / Hyprshutdown

<kbd>SUPER</kbd> <kbd>E</kbd> - open file manager

<kbd>SUPER</kbd> <kbd>V</kbd> - toggle floating window

<kbd>SUPER</kbd> <kbd>R</kbd> - open app launcher

<kbd>SUPER</kbd> <kbd>P</kbd> - toggle pseudo window

<kbd>SUPER</kbd> <kbd>F</kbd> - toggle fullscreen

<kbd>SUPER</kbd> <kbd>J</kbd> - toggle split

<kbd>SUPER</kbd> <kbd>[arrow keys]</kbd> - move focus

<kbd>SUPER</kbd> <kbd>LMB drag</kbd> - move window

<kbd>SUPER</kbd> <kbd>RMB drag</kbd> - resize window

#### Workspaces
<kbd>SUPER</kbd> <kbd>[0-9]</kbd> - switch workspace

<kbd>SUPER</kbd> <kbd>Shift</kbd> <kbd>[0-9]</kbd> - move window to workspace [0-9]

<kbd>SUPER</kbd> <kbd>W</kbd> - toggle special workspace

<kbd>SUPER</kbd> <kbd>Shift</kbd> <kbd>W</kbd> - move active window to special workspace

<kbd>SUPER</kbd> <kbd>mouse scroll</kbd> - scroll through existing workspaces

#### Hyprshot
<kbd>Print</kbd> - screen screenshot

<kbd>SUPER</kbd> <kbd>Print</kbd> - window screenshot

<kbd>SUPER</kbd> <kbd>Shift</kbd> <kbd>S</kbd> - selection screenshot

<kbd>XF86AudioLowerVolume</kbd> - decrease volume

<kbd>XF86AudioMute</kbd> - toggle audio mute

<kbd>XF86AudioMicMute</kbd> - toggle mic mute

<kbd>XF86MonBrightnessUp</kbd> - increase brightness

<kbd>XF86MonBrightnessDown</kbd> - decrease brightness

<kbd>XF86AudioPlay</kbd> - play/pause media

<kbd>XF86AudioPause</kbd> - play/pause media

<kbd>XF86AudioNext</kbd> - next track

<kbd>XF86AudioPrev</kbd> - previous track
